== எளிய சுருக்கம் ==
OK இந்திய அரசியலமைப்பின் கீழ் தனியுரிமை என்பது ஓர் அடிப்படை உரிமையா என்பதைத் தீர்மானிக்க ஒன்பது
    நீதிபதிகள் கொண்ட அமர்வு ஒன்று அமைக்கப்பட்டது.  [பக்கங்கள் 78]
OK தனிஉரிமைக்கான அரசியலமைப்புப் பாதுகாப்பை மறுத்த முந்தைய தீர்ப்புகள் தவறானவை என்று நீதிமன்றம்
    தீர்ப்பளித்தது.  [பக்கங்கள் 1]
OK தனிஉரிமை என்பது வாழ்வுரிமை மற்றும் தனிநபர் சுதந்திரத்திற்கான உரிமையின் இன்றியமையாத பகுதியாகும்
    என்று நீதிமன்றம் அறிவித்தது.  [பக்கங்கள் 431]

== வழக்கின் உண்மைகள் ==
OK முந்தைய உச்ச நீதிமன்றத் தீர்ப்புகள், இந்தியாவில் தனிஉரிமைக்கு அரசியலமைப்பு ரீதியான பாதுகாப்பு
    உள்ளதா என்பதில் குழப்பத்தை ஏற்படுத்தியிருந்தன.  [பக்கங்கள் 78]
OK 18 ஜூலை 2017 அன்று, ஓர் அரசியலமைப்பு அமர்வு தனியுரிமை குறித்த கேள்விகளை ஒன்பது நீதிபதிகள் கொண்ட
    பெரிய அமர்வுக்குப் பரிந்துரைத்தது.  [பக்கங்கள் 78]

== சிக்கல்கள் ==
OK தனிஉரிமை என்பது ஓர் அரசியலமைப்பு உரிமையா என்பது தொடர்பான முந்தைய தீர்ப்புகளின் சரியான தன்மையை
    நீதிமன்றம் தீர்மானிக்க வேண்டியிருந்தது.  [பக்கங்கள் 78]

== தீர்ப்பு (நீதிமன்றம் முடிவு செய்தது என்ன) ==
OK இந்தியாவில் தனிஉரிமை என்பது அரசியலமைப்பால் பாதுகாக்கப்பட்ட ஓர் அடிப்படை உரிமை என்று நீதிமன்றம்
    தீர்ப்பளித்தது.  [பக்கங்கள் 1]
OK தனிஉரிமை அரசியலமைப்பால் பாதுகாக்கப்படவில்லை என்று கண்டறிந்த வரையில் M.P. Sharma வழக்கின் முடிவு
    ரத்து செய்யப்பட்டது.  [பக்கங்கள் 1]
OK தனிஉரிமைக்கான உரிமை அரசியலமைப்பின் உறுப்பு 21 மற்றும் பகுதி III ஆகியவற்றின் கீழ்
    பாதுகாக்கப்படுகிறது.  [பக்கங்கள் 431]

== காரணங்கள் ==
OK நீதிமன்றங்கள் அடிப்படை உரிமைகளின் வரம்பைக் குறைப்பதற்குப் பதிலாக, அவற்றை விரிவுபடுத்தும் வகையில்
    அரசியலமைப்பு விதிகளை விளக்க வேண்டும்.  [பக்கங்கள் 58]
OK உயிரையோ அல்லது தனிநபர் சுதந்திரத்தையோ பறிக்கும் எந்தவொரு சட்டமும் நியாயமான மற்றும் தகுந்த ஒரு
    நடைமுறையை வழங்க வேண்டும்.  [பக்கங்கள் 91]
OK ஒரு பரிந்துரை நீதிமன்றம் தனக்கு அனுப்பப்பட்ட குறிப்பிட்ட சட்டக் கேள்விகளுக்கு அப்பாற்பட்ட
    விஷயங்களில் தீர்ப்பளிக்க முடியாது.  [பக்கங்கள் 404]

== இறுதி உத்தரவு ==
OK தனியுரிமையை ஓர் அடிப்படை உரிமை என்று அறிவித்தும், இதற்கு முரணான முந்தைய தீர்ப்புகளை ரத்து
    செய்தும் இப்பரிந்துரைக்கு பதிலளிக்கப்பட்டது.  [பக்கங்கள் 1]

NOTE: இந்தத் தீர்ப்பு மிக நீளமானது (431 பக்கங்கள்). இந்தச் சுருக்கம் ஒவ்வொரு பக்கத்தையும்
அடிப்படையாகக் கொண்டிருக்காமல், தொடர்புடையவையாகத் தேர்ந்தெடுக்கப்பட்ட 53 பக்கங்களில் உள்ள 54 பத்திகளை
மட்டுமே (தொடக்கப் பகுதி, முடிவுப் பகுதி மற்றும் உண்மைகள், சிக்கல்கள், காரணங்கள் மற்றும் இறுதி
உத்தரவு ஆகியவற்றுடன் மிகவும் பொருந்தக்கூடிய பகுதிகள்) அடிப்படையாகக் கொண்டது. விரிவான அல்லது
சிறுபான்மை கருத்துகள் முழுமையாக விவரிக்கப்படாமல் இருக்கலாம்.

இந்த அமைப்பு நீதிமன்றத் தீர்ப்புகளை நீங்கள் புரிந்துகொள்ள உதவும் வகையில் கல்வி நோக்கிலான விளக்கங்களை
வழங்குகிறது. இது சட்ட ஆலோசனை அல்ல, மேலும் இது வழக்கறிஞர்-வாடிக்கையாளர் உறவை உருவாக்காது. தானியங்கி
சுருக்கங்கள் மற்றும் மொழிபெயர்ப்புகளில் தவறுகள் இருக்கலாம், எனவே முக்கியமான விவரங்களை எப்போதும் அசல்
தீர்ப்புடன் சரிபார்க்கவும். சட்டங்கள், நடைமுறைகள் மற்றும் மனு தாக்கல் செய்வதற்கான காலக்கெடு ஆகியவை
மாறக்கூடியவை, எனவே ஏதேனும் சட்டப்பூர்வ நடவடிக்கையை எடுப்பதற்கு முன் தற்போதைய சட்டம் மற்றும் கால
வரம்புகளை சுயமாகச் சரிபார்த்து, தகுதிவாய்ந்த ஒரு வழக்கறிஞரை அணுகவும்.

இது ஆங்கிலச் சுருக்கத்தின் தானியங்கி இயந்திர மொழிபெயர்ப்பு ஆகும். இயந்திர மொழிபெயர்ப்பில்,
குறிப்பாகச் சட்டச் சொற்களில் பிழைகள் இருக்கலாம். மேற்கோள் காட்டப்பட்ட ஆதாரங்கள் அசல் ஆங்கிலத்திலேயே
வைக்கப்பட்டுள்ளன, எனவே நீங்கள் அவற்றை அசல் தீர்ப்புடன் ஒப்பிட்டுச் சரிபார்த்துக் கொள்ளலாம்.
முக்கியமான எதற்கும், அசல் தீர்ப்பைப் படிக்கவும் அல்லது தகுதிவாய்ந்த ஒரு வழக்கறிஞரிடம் கேட்கவும்.
